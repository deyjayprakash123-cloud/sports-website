## 🏆 Managing Sports Clubs

### Quick Steps to Add a Club

1. **Login** to your admin account
2. Go to **Admin Panel** (click Admin in navigation)
3. Click on **"Sports Clubs"** tab
4. Click **"Add Club"** button
5. Fill in the form:
   - **Club Name** ✅ Required
   - **Logo URL** (optional - paste image URL)
   - **Head Name** ✅ Required
   - **Vice Captain** (optional)
   - **Phone** (optional - format: +91-9876543210)
   - **Email** (optional)
   - **Description** (optional - brief description)
   - **Display Order** (0 = first, higher = later)
   - **Active** (toggle on to show on website)
6. Click **"Create Club"**
7. ✅ Done! Club appears on homepage immediately

### Quick Edit
- Find club in table
- Click pencil icon ✏️
- Update information
- Click "Update Club"

### Quick Delete
- Find club in table
- Click trash icon 🗑️
- Confirm deletion

## 📝 Managing Club Applications ⭐ NEW

### View Applications

1. Go to **Admin Panel**
2. Click **"Applications"** tab
3. See all submitted applications

### Dashboard Overview

**Statistics Cards:**
- **Total Applications** - All time count
- **Pending** - Awaiting your review (yellow)
- **Approved** - Applications you accepted (green)
- **Rejected** - Applications you declined (red)

### Review Applications

**Filter Options:**
- **All Status** - View everything
- **Pending** - Focus on new applications
- **Approved** - See accepted members
- **Rejected** - Review declined applications

### Take Action

**Approve an Application:**
1. Find application in table
2. Click green checkmark ✓
3. Status changes to "Approved"
4. Consider calling the applicant

**Reject an Application:**
1. Find application in table
2. Click red X button ✗
3. Status changes to "Rejected"
4. Optionally provide feedback

**Delete an Application:**
1. Find application in table
2. Click red trash icon 🗑️
3. Confirm deletion
4. Permanently removed

### Application Details

Each application shows:
- **Applicant Name** - Who applied
- **Club** - Which club they want to join
- **Phone** - Contact number (clickable)
- **Skills** - Their experience and abilities
- **Status** - Current status with badge
- **Date** - When they applied

### Best Practices

**Daily Routine:**
1. Check Applications tab
2. Filter by "Pending"
3. Review each application
4. Call promising candidates
5. Approve or reject
6. Update club rosters

**Tips:**
- ✅ Review applications within 2-3 days
- ✅ Call applicants before approving
- ✅ Provide feedback when rejecting
- ✅ Keep records (don't delete immediately)
- ✅ Track application trends

## 🏅 Managing Tournaments

### Add a Tournament

1. Go to **Tournaments** tab
2. Click **"Add Tournament"**
3. Fill in details:
   - **Sport Name** ✅ Required
   - **Logo URL** ⭐ NEW (optional)
   - **Status** (upcoming/ongoing/completed)
   - **Rules** (tournament rules)
   - **Schedule** (dates and times)
4. Click **"Save"**

### Add Tournament Logo ⭐ NEW

**Why Add Logos?**
- Makes tournaments more attractive
- Professional appearance
- Easy recognition
- Sponsor visibility

**How to Add:**
1. Find or create logo image
2. Upload to image hosting (Imgur, Cloudinary)
3. Copy direct image URL
4. Paste in "Logo URL" field
5. Save tournament

**Logo Tips:**
- Use square images (300x300px)
- PNG with transparent background
- Under 500KB file size
- High quality, clear design
- Relevant to the sport

## 👥 Managing Admins

### Make Someone an Admin

1. Go to **Admin Panel**
2. Click **"Admins"** tab
3. Scroll to **"Regular Users"** section
4. Find the user
5. Click **"Make Admin"** button
6. Confirm
7. ✅ They now have full admin access!

### Remove Admin Access

1. Go to **"Admins"** tab
2. Find admin in **"Administrators"** section
3. Click **"Remove Admin"** button
4. Confirm
5. ✅ They're now a regular user

**⚠️ Note**: You cannot remove your own admin access!

## 🔥 Pro Tips

### For Clubs:
1. **Logo Size**: Use square images (500x500px recommended)
2. **Logo Format**: PNG with transparent background works best
3. **Descriptions**: Keep under 100 characters for best display
4. **Order**: Use multiples of 10 (10, 20, 30) for easy reordering
5. **Inactive vs Delete**: Mark inactive instead of deleting to preserve history

### For Applications:
1. **Quick Review**: Set aside 15 minutes daily
2. **Call First**: Contact before approving
3. **Be Prompt**: Respond within 2-3 days
4. **Keep Records**: Don't delete immediately
5. **Track Trends**: Monitor which clubs are popular

### For Tournaments:
1. **Add Logos**: Makes tournaments more professional
2. **Update Status**: Keep status current (upcoming → ongoing → completed)
3. **Clear Rules**: Write detailed, easy-to-understand rules
4. **Accurate Schedule**: Include dates, times, and locations
5. **Regular Updates**: Post results promptly

### For Admins:
1. **Be Selective**: Only promote trusted users
2. **Document**: Keep a list of all admins
3. **Review**: Check admin list monthly
4. **Communicate**: Tell users when you change their role
5. **Backup**: Always have at least 2 admins

## 🆘 Common Questions

### Q: How do I upload a logo?
**A**: Upload image to any image hosting service (Imgur, Cloudinary, etc.) and paste the URL in the "Logo URL" field.

### Q: Can I have multiple admins?
**A**: Yes! You can have unlimited admins.

### Q: What happens if I delete a club?
**A**: It's permanently removed from the database. All applications for that club are also deleted. Consider marking it inactive instead.

### Q: Can admins edit each other's content?
**A**: Yes, all admins have equal permissions.

### Q: How do I change the order of clubs?
**A**: Edit each club and set the "Display Order" number. Lower numbers appear first.

### Q: Can users see inactive clubs?
**A**: No, only admins can see inactive clubs in the admin panel.

### Q: How do I know if someone applied to a club?
**A**: Check the Applications tab. You'll see a count of pending applications.

### Q: Can I edit an application?
**A**: No, but you can approve, reject, or delete it. Contact the applicant if changes are needed.

### Q: What if a tournament logo doesn't show?
**A**: Verify the URL is correct and the image is publicly accessible. Test the URL in your browser.
