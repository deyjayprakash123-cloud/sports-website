# Quick Start: Customizing Your Sports Society Website

## 🎯 What You Can Customize

Your College Sports Society website now has powerful customization features that let you:
- ✅ Edit contact information (email, phone, address)
- ✅ Add social media links (Facebook, Twitter, Instagram, YouTube, LinkedIn)
- ✅ Create and manage hero carousel slides
- ✅ Update site name and tagline
- ✅ All without touching any code!

---

## 🚀 Getting Started (5 Minutes)

### Step 1: Access Admin Panel
1. Log in to your website
2. Click **Admin** in the navigation menu
3. You'll see 10 tabs for managing different aspects

### Step 2: Update Contact Information
1. Click the **Settings** tab
2. Find the "Contact Information" section
3. Update:
   - **Email**: Your sports society email
   - **Phone**: Contact phone number
   - **Address**: Your college address
4. Click the **💾 Save** button next to each field

### Step 3: Add Social Media Links
1. Still in the **Settings** tab
2. Find the "Social Media Links" section
3. Add your social media URLs:
   ```
   Facebook:  https://facebook.com/yourpage
   Twitter:   https://twitter.com/yourhandle
   Instagram: https://instagram.com/youraccount
   YouTube:   https://youtube.com/@yourchannel
   LinkedIn:  https://linkedin.com/company/yourcompany
   ```
4. Click **💾 Save** after each URL
5. Icons will automatically appear in the footer!

### Step 4: Customize Hero Slides
1. Click the **Hero Slides** tab
2. You'll see the default slide
3. Click **✏️ Edit** to modify it, or **Add Slide** to create new ones

#### Creating Your First Custom Slide:
1. Click **Add Slide**
2. Fill in:
   - **Title**: Your main message (e.g., "JOIN OUR TEAM")
   - **Subtitle**: Supporting text (e.g., "Be part of something great")
   - **Primary Button Text**: "Register Now"
   - **Primary Button Link**: "/register"
   - **Secondary Button Text**: "View Events"
   - **Secondary Button Link**: "/tournaments"
3. Click **Create**
4. Your new slide is live!

## 💡 Pro Tips

### For Best Results:
1. **Keep hero titles short**: 3-5 words maximum
2. **Use action buttons**: "Register", "Join", "Explore"
3. **Add 2-3 slides**: Don't overwhelm users
4. **Test social links**: Make sure URLs are correct
5. **Update regularly**: Keep content fresh

### Common Mistakes to Avoid:
- ❌ Don't leave default placeholder URLs (like `https://facebook.com`)
- ❌ Don't create too many hero slides (3-5 is ideal)
- ❌ Don't forget to mark slides as "Active"
- ❌ Don't use broken links in buttons

## 🔧 Troubleshooting

### Social Icons Not Showing?
- Make sure URLs start with `https://`
- Don't use default placeholders
- Click Save after entering each URL

### Hero Slide Not Appearing?
- Check if slide is marked as "Active"
- Verify the title field is filled
- Check display order number

### Changes Not Saving?
- Ensure you're logged in as admin
- Click the Save button
- Refresh the page to see changes
